# 手机 App 布局 PWA 验证

日期：2026-10-24；版本 `2.20.2-personal.5`；分支 `feat/iphone-mobile-pwa`。

## 已确认的实现与构建

- iPhone 采用共享 Web 前端的 PWA 构建，不生成或使用 IPA，不需要 Mac 或每 7 天签名。
- manifest `display: standalone`、Apple Web App 元信息、图标及全屏视频入口保留。
- 手机四项底部导航；搜索输入与按钮、底栏、面板关闭等主要操作适配触控；键盘输入时收起底栏。
- 首页只显示真实历史的继续观看卡，没有预设假海报、影片、私人 API 或用户默认密码。
- 详情为手机底部面板，桌面/平板仍响应式；API、播放器和本机数据逻辑沿用。
- `npm test`：48 个文件、663 项通过。
- `npm run build:iphone`：静态导出成功，未包含 Next.js API，完整应用资源生成带摘要的预缓存。
- 当前安装页仅引导 Safari 添加到主屏幕，不输出旧 `.mobileconfig`。

## 安装与发布边界

用户已说明目前只能使用 iPhone。原有“不部署云端”约束未被自动取消。
本地静态构建文件和截图不能让手机凭空安装；普通 PWA 首次下载和更新需要安全的 HTTPS 来源。
若用户同意静态安装分发，将另行记录准确提交及发布结果；未获同意不自动公开或发布。
完整资源缓存后界面可在本机启动，但 iOS 可能回收缓存，不能保证永久无安装来源依赖。

所有真实 iPhone 项目仍待用户测试：Safari 添加主屏幕、独立窗口、安全区、系统键盘、
原生 HLS 声音/全屏/横屏、倍速、后台及系统回收恢复、缓存保留和真实片源兼容性。

## 浏览器集成验证

系统 Chromium 手机触控模拟完成 10 组检查，全部通过：首次 PIN、完整 SW 应用缓存、底栏及键盘、
源管理/失败隔离、详情选集和收藏、真实合成 MP4 解码及刷新续播、真实历史继续观看、尺寸适配、
安装页、断网新页面冷启动和本地数据保留。

尺寸覆盖 430×932、390×844、320×740、932×430 横屏、1280×800 平板；首页、设置、详情、
安装页及离线场景无横向溢出。底栏、关闭及主要触控区域检查通过，滚动到底后页脚和浮层无底栏遮挡。
发现横屏关闭按钮仍为 32px 后，将规则调整为触控设备通用 44px，并完成复测。
