# 手机独立版的界面与本地数据

构建变量 `NEXT_PUBLIC_APP_MODE=standalone` 选择独立模式，原有服务端版本仍保留。

- 首页提供片名搜索，以及直接播放 HTTPS MP4/m3u8 链接的入口。
- 「Apple 官方试播」只在点击后打开 Apple 开发者页面公布的 HLS 示例，未预加载，
  未把测试素材伪装为影视库。来源：[Apple 示例页面](https://developer.apple.com/streaming/examples/advanced-stream-hevc.html)。
- 点播源仍可在设置添加、编辑、删除及启停。新增源要求 HTTPS，旧 HTTP 配置保留并提示修改。
  搜索失败会显示源站或浏览器访问限制，其他来源和设置仍能使用。
- 点播收藏与观看历史继续使用 IndexedDB。直接链接使用保留的 `__direct__` 来源标识，
  以用户填写的链接作为本机定位信息；收藏、历史与逐集进度可恢复，并随配置导出备份。
  带签名的链接可能过期，更新链接后需重新添加，应用不会保存或下载视频内容。
- 图片只直连原始 HTTPS 地址，不用内置或未知公共代理；加载失败使用占位。
- 独立模式关闭后台推荐、画质探测、直播入口和视频下载入口，不启动下载管理器，
  不经 `/api/proxy` 回退，也不执行整集 JavaScript 预取。这些入口在服务端版仍保留。
- iPhone 优先原生 HLS/HTMLVideo。不可直连或不兼容编码会说明失败，不能靠静态 PWA 绕过源站限制。
- 顶栏保留主题、安装、收藏、历史与设置；名字、图标和颜色继续由统一品牌模块管理。

新增纯函数回归测试验证 HTTPS/账号密码/相对地址边界、原始签名链接、直接播放历史定位及图片不走代理。
真实 iPhone 的原生全屏、后台恢复及实际来源仍需手机验收；浏览器模拟不替代真机结果。
