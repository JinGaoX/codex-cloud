# iPhone PWA 与品牌配置

本阶段沿用 Next.js Web 前端、ArtPlayer 与本机 IndexedDB。PWA 安装并不替代服务端：搜索、详情和代理仍需部署后的 HTTPS 服务。手机可在 Windows 关机后联网访问云端服务。

## iPhone 15 Pro Max 安装

1. 在 Safari 打开部署后的 HTTPS 地址，完成站点登录。
2. 点分享按钮，选择「添加到主屏幕」。如果系统显示「作为网页 App 打开」，保留开启。
3. 从主屏幕图标启动。独立界面不显示 Safari 地址栏与标签页。
4. 建议在主屏幕 App 内添加合法 API 并配置收藏。不同 iOS 版本中，Safari 与主屏幕 App 的网站数据可能独立；需要迁移时使用配置导入导出。

浏览器设置、系统版本或托管平台登录跳转可能影响安装与会话，需实际设备确认。iPhone 没有可由网页调用的安装接口，应用内安装按钮提供上述指引。安卓支持安装事件的浏览器可显示原生安装提示。

## 缓存与更新

- `public/sw.js` 在 HTTPS（或 localhost）注册，缓存公开的 `/_next/static/` 构建资源、图标和 `offline.html`。
- 不缓存页面 HTML、React Server Component 数据、API、鉴权响应、搜索结果、海报或视频。播放模块原有的媒体缓存属于另一个功能，不由 PWA Service Worker 接管。
- 文档始终先联网；网络断开时显示离线说明。当前版本不承诺完整离线启动或离线搜索/播放。
- 缓存公开资源上限为 100 条，写入失败不阻断成功的网络响应。
- Service Worker 更新等待用户在首页点「更新并重新打开」，不主动刷新正在播放的页面；其他标签页触发更新时也不强制刷新本页面。
- 修改 `sw.js` 会触发更新检测；修改应用代码会生成新的构建资源路径，下次正常加载时获取新页面。无需为了更新界面清除网站数据。若将来改变缓存格式，递增 `CACHE_NAME` 的版本后部署。

本地设置、收藏和历史不等于云端备份。iOS 可以回收网站存储，用户清除数据或卸载也可能移除记录。「申请保留本地数据」只提交浏览器支持的持久存储请求，不保证授予。请定期导出。

## 替换名称、图标与主题

编辑 `src/lib/app-brand.ts` 中公开的 `APP_BRAND`，前端品牌、页面元数据、manifest 和 Apple 主屏幕标题共用它。不要在此模块加入密码、API 密钥或私有配置。

- `name` / `shortName`：名称与主屏幕短标题。
- `icons`：推荐替换 `public/icons/` 对应 PNG：192×192、512×512，以及 180×180 Apple Touch 图标；保留 `public/favicon.ico` 作为浏览器兜底。PWA 使用 `purpose: any`，不将现有未验证安全区的图标虚标为 maskable。
- `themeColor` / `backgroundColor`：PWA 与系统界面主题。
- `colors`：浅色/深色强调色用 RGB 三元组，品牌渐变用颜色字符串；更换后需检查文字对比度。离线说明页故意不加载业务脚本，可按需单独调整其配色。

修改后重新构建和部署。iOS 已安装图标与名称可能保持旧值，可在导出本地配置后移除旧图标并重新添加，再导入记录。后续 Capacitor 的原生显示名称和启动图标是打包资源，仍需由相同品牌信息生成原生资源；Web 业务 UI 无需重写。

## 必须在真机验证

- Safari 添加主屏幕后的独立启动、图标与系统状态栏；iPhone 竖/横屏安全区、键盘弹出后的搜索输入。
- 登录会话关闭重开后的保留，Safari 与主屏幕 App 的配置迁移。
- 断网启动显示离线说明，恢复网络可重新进入，已有收藏/历史仍在。
- 新部署后更新提示可用，观看中不被自动刷新，更新不删除配置。
- 安装入口在主屏幕独立界面自动隐藏；设置与详情抽屉在刘海和 Home 指示条附近仍可操作。

自动化测试仅验证 Service Worker 的缓存边界、断网兜底与配额失败处理；不能替代 Safari 安装或实际媒体播放测试。
