# 本机密码与 iPhone 快捷入口验证

日期：2026-10-23；版本 `2.20.2-personal.3`；分支 `feat/iphone-quick-login`。

本轮提供设备本地的六位数字密码及主屏幕安装入口，不新增账号服务器或 OAuth。
安装站点继续保持原有仅本人访问权限，首次访问或平台登录失效仍可能需要 ChatGPT 验证。
本机密码不替代该验证，不加密收藏、配置和历史，亦不保护公开的程序源文件。

## 安装与真机待验

推荐 Safari 打开站点完成平台验证，再分享 → 添加到主屏幕，从图标首次打开时设置密码。
若系统显示“作为网页 App 打开”，保持开启。Safari 与主屏幕 App 的本地存储可能独立，
不假定此前设置、收藏、PIN 会自动迁移。

备用描述文件未签名，仅创建可移除的 WebClip；用户需要自己在 iPhone 设置中确认安装。
它不是 IPA 或快捷指令文件，不能静默安装，也不会绕过托管访问验证。

Web App 全屏/安全区、数字键盘、长时间原生 HLS 播放、横屏、后台和锁屏恢复、iOS 缓存回收。
