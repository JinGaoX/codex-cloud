# 本机数据与配置迁移

第一阶段保留官方的 localStorage 设置与 IndexedDB 历史、逐集进度，新增 IndexedDB v4 点播收藏表。升级不删除旧表。影片收藏只保存源地址、影片 ID、标题和海报等定位信息，进入详情时重新请求源站；不缓存播放链接或下载影视资源。

- 搜索结果进入详情后点「收藏」，再通过顶部心形按钮查看、搜索、取消收藏及重新选集。
- 历史与收藏独立，清空观看历史不会删除收藏。删除数据源也不会删收藏；收藏中的原 API 地址可用于重新读取详情，但源站关闭后无法保证访问。
- 设置 → 数据 → 导出配置现在包含源设置、订阅、偏好设置、收藏、观看历史及每一集的播放进度。原版导出的历史无法被原版导入器读回的问题已修正。
- 支持官方旧 `sourceCode` / `vod_id` 历史格式；没有逐集进度的旧备份会从历史恢复当前一集的位置。旧文件没有收藏类别时保留本机收藏。文件中明确包含的数据类别会替换本机对应类别。
- 导入先解析所有片段，再通过 IndexedDB 事务写入；写入失败回滚。成功后同步设置内存态并立即刷新。
- 设置在页面隐藏、pagehide 及卸载前主动刷新节流缓冲，降低 iOS 切后台时丢失设置的风险。

本地存储不等于云同步。iOS 可能把 Safari 与主屏幕 App 的存储分开，卸载、清除网站数据或系统回收仍可能丢数据。建议先添加主屏幕，再配置源，并定期导出到「文件」保存。配置文件可能含私人 API 地址，请勿提交到公开仓库；此项目不保存密码或 API 密钥到示例配置。

## 已自动验证

`src/lib/db.test.ts` 使用 fake-indexeddb 验证：收藏去重与删除、完整备份往返、旧格式迁移、损坏文件不覆盖已有数据、写入异常事务回滚，以及官方 v3 → v4 数据库升级。测试源和海报使用 `example.com` fixture，不代表可用影视 API。

## 手机仍需验证

从主屏幕 App 中添加合法 API、收藏影片、播放一段后切后台、恢复进度、导出到「文件」、清空后导入、关闭并重开 App；分别检查收藏、源开关、历史及不同剧集进度。云端数据库测试不能替代 Safari 的下载、存储回收与真实视频播放验证。
