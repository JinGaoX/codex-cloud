## 安装与首次试用

1. 用 iPhone Safari 打开安装地址，分享 → 添加到主屏幕 → 添加。
2. 从新图标联网打开，自己设置并确认 6 位本机密码，无需注册或苹果签名。
3. 等“正在将应用保存到本机”提示消失，再尝试断网关闭重开；iOS 可能回收缓存，须定期导出数据备份。
4. 点“Apple 官方试播”，检查声音、暂停、拖动、倍速、横屏及全屏。
5. 在设置内添加本人可用的 HTTPS 影视 API，再验收搜索、选集、换源、收藏和续播。
   纯浏览器版不能解除源站 CORS、防盗链、证书或格式限制，不保证所有源可用。

如已有旧版并出现“应用更新已就绪”，点“更新并重新打开”。
程序完整缓存后不依赖 Windows 开机；搜索与在线播放仍需网络，更新或缓存丢失时仍需安装来源。
PWA 不需要 Mac、IPA 或每 7 天签名。
