# 分辨率和首页推荐

版本：`2.20.2-personal.8`，开发分支 `feat/pwa-discovery-playback`。

本轮继续使用共享 Web 前端，iPhone PWA 无需重新安装；未来安卓 Capacitor 可复用。
现有安装地址：https://jingaox.github.io/codex-cloud/ 。

## 完整分辨率

`1920×1080` 表示取得的宽和高，不用档位名或码率猜测宽度。
源站播放清单声明的尺寸与播放器解码后的实测尺寸分别标注；自适应视频可能在播放中切换尺寸。
详情仅检查所打开影片首集，最多读取64KiB播放清单和96KiB媒体前缀，6秒超时；不自动播放、不抓取加密密钥、不批量探测搜索结果。
没有可读尺寸时显示未知，仍可直接播放；不会因此拦住选集或清空搜索结果。
浏览器的跨域限制、防盗链、加密及格式可能阻止预览时读取尺寸，播放后有机会补全。

## 首页推荐

复用原项目已有的 [60s API](https://github.com/vikiboss/60s) 推荐来源，浏览器直连 `https://60s.crystelf.top`。
提供豆瓣电影周榜、国产剧周榜、海外剧周榜、国内和海外综艺榜，以及百度热播剧榜。
通过 HTTPS 只读取公开榜单，不发送用户 API 配置、搜索词、PIN 或观看历史。
推荐只提供影片信息，点击后向用户自己启用的片源搜索，不保证片源一定收录或能播放。
8分以上、喜剧仅筛选当前榜单内符合条件的影片，不声称是全站评分排行或完整电影分类库。
保留来源原始顺序、实际提供的名次与评分，不用百度热度冒充评分；无评分的百度榜不显示评分与喜剧筛选。
页面标注本机获取时间，不冒充来源更新时间。推荐加载与搜索、播放分离，失败可重试。
设置 → 偏好设置 → 首页与内容可关闭推荐，新开关与旧全栈推荐设置相互独立。
来源免费、无密钥，社区公共接口不承诺服务可用性。
