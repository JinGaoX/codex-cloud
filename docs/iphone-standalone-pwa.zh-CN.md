# VIP影视：iPhone 15 Pro Max 独立版 PWA

当前版本：`2.20.2-personal.11`。当前安装入口：
https://jingaox.github.io/codex-cloud/ 。无需 ChatGPT 登录、开屏 PIN、Mac 或苹果开发者签名。
用户已同意公开 HTTPS 静态托管；当前域名与原有存储标识保持不变。

此前 `chatgpt.site` 入口继续保留并同步程序更新。两个域的本机数据彼此独立；
旧 Site 的 Cloudflare 拦截是否在手机上解除仍需用户实际验证，不应清除原站数据来排查。
历史说明见[托管恢复记录](pwa-hosting-recovery.zh-CN.md)。

## 安装

1. 在 iPhone Safari 打开上述地址。点分享 → 添加到主屏幕；如出现“作为网页App打开”，保持开启。
2. 从主屏幕图标打开，即可进入首页。本版不要求设置或输入本机密码。
3. 在设置中添加、勾选自己合法可用的 HTTPS JSON 片源，再搜索、选集和播放。

手机界面提供首页、收藏、历史和设置；横屏及平板保留多列布局。
安装页 `/install.html` 提供简短步骤，当前构建不输出 WebClip 描述文件。

## 更新与图标

- 从 personal.8 升级时，仍点旧版“更新并重新打开”；完成后直接进入 VIP影视，不再验证旧PIN。
- 新版后续更新入口：设置 → 数据 → 应用更新 → 检查更新 → 更新并重新打开。
  新版静默缓存程序，主页不再显示安装、离线、缓存或更新横条；播放中阻止更新重载。
- 更新保留 API、收藏、历史、进度与旧PIN记录，但旧PIN不再被读取为入口条件。
- iOS可能保留原桌面名称/图标，程序内部品牌已更新。可在Safari重新添加VIP影视图标，
  先保留旧入口并确认记录；Safari和主屏幕存储可能独立，不要通过清除网站数据更换图标。

## 播放与定时

影视搜索/详情和媒体由设备直接访问来源，不运行 Next.js API、搜索服务器或视频代理。
源站 HTTPS、CORS、防盗链和媒体格式仍会影响播放，PWA不能自行解除所有限制。
搜索结果提供完整真实剧集时可以短时复用；详情失败可按已有片名、同源和原影片ID恢复。
边界见[详情恢复](source-detail-recovery.zh-CN.md)。

详情可显示真实读取的完整尺寸，播放页显示当前解码尺寸。首页仅使用公开真实榜单，
高分/喜剧筛选作用于当前榜单，出处和对应源码保留在关于页。
推荐海报在原图拒绝访问时会尝试原项目已有的公开备用图床，刷新榜单可重新加载；第三方图片可用性仍取决于网络与服务状态。
片源提供的每集原始标题会在详情与播放页显示，长标题完整换行；只有序号的片源继续显示数字。

播放页可选15/30/60/90分钟或本集结束后停止，支持取消和倒计时，停止后阻止自动连播。
本标签的定时状态跨选集、换源、刷新保留；暂停期间仍按实际时间计算。
iOS完全挂起网页时无法保证后台精确到秒停止，恢复与每次起播会重新检查截止。

## 本机数据与离线

首次安装和更新需可用的HTTPS来源。完整保存后，界面、设置、收藏、历史可离线打开，
搜索与在线播放仍需网络；程序缓存不等于下载影片。可在导出备份后断网重开确认。

公开程序资源完整预缓存并逐项校验SHA-256，源API、视频、Range请求和私人配置查询不进入共享缓存。
新版本只有完整保存后才可激活，失败保留旧完整版本；保留近期旧构建资源以支持另一标签的播放。
项目路径worker限制于 `/codex-cloud/`，不会接管或清理其他项目缓存；根路径构建单独使用 `/`。

本机收藏、历史和配置并非云同步，请在设置中定期导出。浏览器清理、卸载和系统存储回收可能移除记录。
此应用没有给iPhone安装Node.js，也不需要Windows开机。
