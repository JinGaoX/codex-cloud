# iPhone 15 Pro Max 实机验收

所有下列项目初始状态为 **待用户实测**。云端构建、接口测试和桌面浏览器不能替代 iOS 媒体解码、系统全屏、后台恢复、存储和主屏幕安装验证。

## 准备与安装

记录 iOS 版本、测试日期、应用提交号、真实部署域名、Wi-Fi/蜂窝网络和源名称（避免公开含 token 的完整播放 URL）。只使用自己有权访问的真实 API 与测试内容，至少准备一条可用 MP4、一条 HLS/m3u8 和同一影片两条线路；没有该内容就标“未测”，不要当通过。

1. Windows 保持关机。手机使用 Wi-Fi 或蜂窝网络，Safari 打开真实 Production **HTTPS** 地址，确认不是 `localhost`、Windows 局域网 IP 或仅随开发会话存在的临时端口。
2. 输入部署者设置的站点密码，进入设置，添加 API、编辑名称、停用再启用，确认刷新后保存。先不要导入来历不明的源清单。
3. Safari 分享菜单 → **添加到主屏幕** → 添加；部分 iOS 显示“作为 Web App 打开”，保持开启。若分享菜单未显示添加项，可在“编辑操作”中加入。[Apple 安装说明](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios)
4. 从主屏幕图标重新启动。检查名称、图标、深色主题和刘海/底部安全区，确认独立窗口没有普通 Safari 地址栏和标签页；如需再次登录属可记录行为，不预设与 Safari 标签页会话共享。

## 判断与反馈

基础验收至少覆盖：主屏幕独立启动、MP4/HLS 声画、搜索失败隔离、选集换源、进度/收藏、完整导入导出和 Windows 关机后的新请求。若仅少量片源失败，先记录格式/线路/网络，不能据此假设整个 App 损坏；若所有搜索失败，检查登录与云服务；若清单成功但视频失败，继续检查分片/编码、代理和 Range。

反馈时提供失败用例、iOS 版本、应用提交号、错误文字和脱敏截图。不要公开密码、cookie、配置文件或带签名/token 的 URL。必要时在可信授权渠道提供可复现的合法 API；未提供前相应真实源兼容性标“未测”。
