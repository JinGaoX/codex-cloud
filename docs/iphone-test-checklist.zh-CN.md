# iPhone 15 Pro Max 独立版实机验收

核查日期：2026-10-23，适用 `feat/iphone-quick-login`。以下项目均为 **待用户实测**，不是手机通过记录。
云端构建、单元测试和桌面浏览器不能替代 iOS 主屏幕安装、媒体解码、系统全屏、后台恢复与本机存储验证。

当前版本是静态独立 PWA：托管平台分发应用文件并管理私人网址的访问验证；手机直接请求用户配置的
HTTPS API 和媒体。没有 Next.js 搜索服务、站点 PASSWORD 登录或视频代理。本机 6 位 PIN 只锁定界面，
不加密配置/收藏/历史，也不替代托管平台的 ChatGPT 访问验证。

## 准备与安装

记录 iOS 版本、日期、应用提交号、真实部署域名、Wi-Fi/蜂窝网络和源名称，避免公开含 token 的完整 URL。
只使用自己有权访问的 API/内容，准备允许浏览器跨域访问的 HTTPS CMS API、可用 MP4、HLS/m3u8 和同片两条线路。
没有对应内容就标“未测”。原生视频与 hls.js 的跨域要求可能不同；API 可搜索不代表媒体的每个分片也可播放。

1. Windows 保持关机。用 iPhone **Safari** 打开真实 HTTPS 地址的 `/install.html`；如从 ChatGPT 内打开，
   先通过菜单转到 Safari。入口不能是 `localhost`、Windows 局域网 IP 或依赖开发会话的临时端口。
2. 首次访问私人网址或平台会话失效时，使用有权访问此 Site 的 ChatGPT 账号完成**平台访问验证**。
   点击安装页“打开 LibreTV”，先使用 Safari 分享 → **添加到主屏幕**；如显示“作为网页 App 打开”，保持开启。
3. 回到主屏幕，从新图标首次联网启动，再自行设置并确认 **6 位数字本机 PIN**，没有预设 PIN、不需另注册应用账号。
   Safari 与主屏幕 App 的密码、缓存、收藏及历史可能独立，不能仅凭 Safari 已打开过就认定安装完成。
4. 等待“正在将应用保存到本机”提示消失。若未保存成功，检查网络/存储后重开；随后在这个主屏幕入口的设置内
   添加实际合法 HTTPS API，保存并测试。源站拒绝 CORS、仅 HTTP 或依赖网页解析时需更换可直连源。
5. 保存测试数据并导出备份，断网关闭再从主屏幕重开；确认能本机 PIN 解锁并查看界面、设置、收藏及历史。
   搜索和新视频仍需联网。私人托管网址的在线访问/更新仍可能要求平台验证，PIN 不会替代它。

Safari 添加方法参考：[Apple 主屏幕 Web App 说明](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios)。
可选 WebClip 方法见下表和[独立版安装说明](iphone-standalone-pwa.zh-CN.md)，Safari 方法是推荐入口。

## 判断与反馈

基础验收至少覆盖：独立主屏幕启动、PIN 设置/错误/修改/离线解锁、MP4/HLS 声画、坏源隔离、选集换源、
进度/收藏、配置往返和 Windows 关机后的新请求。全部搜索失败时先检查手机网络、源站 HTTPS/证书/CORS；
平台验证主要影响在线打开/下载应用文件。清单可取但播放失败时继续检查媒体分片/编码和 Range，当前无视频代理。

忘记 PIN 无法找回；清除该网站本机数据后重新设置会丢失本机配置/收藏/历史，已有导出备份可重新导入。
不要为了测试“忘记密码”清掉唯一数据副本。系统清理、卸载、入口变化的实际存储影响均需实机确认。
