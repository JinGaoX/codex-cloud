# iPhone PWA 安装入口与运行边界

PWA 通过 Safari“添加到主屏幕”，以独立窗口打开，可隐藏普通浏览器的地址栏和标签页。
它不使用 IPA，不需要 Mac 或苹果应用签名，也没有免费个人 IPA 签名的每 7 天续签要求。

## 本轮条件

用户目前只能使用 iPhone。此前要求“不部署到云端”，在解释 HTTPS、公开访问与静态托管后，
用户明确回复“那就发布吧，发布之后把这个项目帮我备份到GitHub上”，本轮据此获准公开发布。
安装入口及准确版本见[发布记录](iphone-pwa-release.zh-CN.md)。这不代表以后可擅自上传私人配置或改变数据保存方式。

普通 PWA 首次安装及获取新版本需要可以访问的 HTTPS 程序来源。只有手机、没有可用的本地安装服务器，
并拒绝任何 HTTPS 托管时，无法立即把这次新版本安装为完整 PWA。把 ZIP 存进“文件”或仅添加网页图标，
不能替代 HTTPS、Service Worker 和完整程序资源的安装。

## 静态分发与业务服务

HTTPS 安装页可以只分发公开的程序文件，手机自行保存配置、收藏、历史并处理搜索和播放；
这与在云端运行搜索聚合、视频代理或私人数据服务不同。但分发程序文件仍然属于托管，
必须获得用户对该安装来源的明确同意，不能因其只提供静态文件就称为“没有托管”。

若以后明确允许临时或长期 HTTPS 安装来源，仍须保留其实际访问权限；同意安装不等于同意公开网址，
本机 PIN 也不能代替托管平台的访问控制。

## 手机独立运行的条件

1. Safari 打开合法 HTTPS 安装地址，按系统流程添加到主屏幕。
2. 从主屏幕图标首次联网启动，等待 Service Worker 激活且全部程序资源保存成功。
   不假定 Safari 标签页与主屏幕 App 自动共享缓存或本地记录。
3. 保存完成后，可从本机资源启动并查看已有配置、收藏和历史；搜索及在线播放仍需联网访问用户配置的片源。
   当前独立版需要片源支持 HTTPS 与所需的跨域访问，不能靠 PWA 自动解除源站限制。
4. iOS 可能在存储压力、清除网站数据或删除入口等情况下移除缓存和记录。
   更新、重新安装或资源丢失后恢复，仍需要可用的安装来源。请定期导出私人数据备份。

以上是实现条件，不代表当前版本已在真实 iPhone 15 Pro Max 上完成安装、冷启动和播放验收。

## 以后可评估：Windows 临时提供本地 HTTPS

若将来能够临时开启 Windows，可评估同一 Wi-Fi 下由电脑提供 HTTPS 静态文件，仅在初装、恢复及更新时运行。
局域网普通 HTTP IP 不满足可靠的 Service Worker 安装条件，不能把电脑的 `localhost` 直接当成手机地址。
[MDN 安全上下文说明](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts)

本地 HTTPS 需要与固定 IP 或主机名匹配的服务器证书，并在 iPhone 上安装对应的公开根证书、手动开启完全信任。
证书私钥应始终留在用户电脑，不发送到手机、不放入静态文件目录或源码仓库。
相关步骤可参考 [Apple 手动证书信任说明](https://support.apple.com/en-in/102390)及
[mkcert 官方移动设备说明](https://github.com/FiloSottile/mkcert#mobile-devices)。

本轮没有实现或交付 Windows 本地 HTTPS 安装器，也没有验证其实际 iPhone 安装链路；
不能承诺届时无需配置或一定一次成功。完成主屏幕 App 的首次完整缓存后，才可关电脑并进行真实冷启动测试。
