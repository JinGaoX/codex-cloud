## 合成素材播放检查

使用本机 FFmpeg 生成 **20 秒、320×180、H.264/AAC** 测试图与正弦音，并转为 HLS。
仅在本机 HTTP 夹具服务器提供；没有访问影视资源站，没有把夹具装入生产源列表。
使用实际浏览器视频解码，不以“接口返回 200”冒充播放成功。

- 原生 HTMLVideo MP4：解码得到 320×180，时长 20 秒，进度实际前进；暂停、拖到第 6 秒、1.5 倍速可用。
- 同一播放器切 MP4 → hls.js HLS → MP4：三次均解码，HLS 时长约 20.039 秒。
- 三集分别保存约 6、6、8 秒，检查 IndexedDB 中三个独立进度键，没有串写。
- 网页全屏覆盖页面 UI，退出后正常；刷新后从保存的第 8 秒附近恢复。
- 此检查发现并修复了 ArtPlayer 内部遮罩拦截「点击播放」触控的问题。

浏览器 QA 脚本/截图/结果 JSON 保留在本次交付的独立 QA 证据包及当前环境
`/workspace/libretv-qa/`；不把合成媒体、运行数据和私人配置提交到源码。
这些脚本使用当前云环境安装的 Playwright、`/usr/bin/chromium`、FFmpeg，
运行 `node playback.cjs` 与 `node check.cjs` 前需保留相同项目路径和测试素材目录。
便于以后通用运行的业务回归测试已在项目 `src/**/*.test.ts`，通过 `npm test` 执行。

## 未验证及限制

- **iPhone 真机未测试**：Chromium 手机尺寸不是 iOS WebKit，不能证明原生 HLS、系统全屏、
  画中画、倍速、旋转、锁屏/后台恢复、Safari 安装与系统存储回收的实际行为。
- **真实影视 API/影片未测试**：用户尚未配置合法实际源；不会宣称所有片源或编码可播放。
  合成素材不覆盖 DRM、源站签名、跨境/区域、Referer、实际 CDN 和网络问题。
- 代理响应头超时/Range 的回归测试使用受控上游；本机合成媒体直连，不绕过 SSRF 去代理 localhost。
  上线后仍需测试云平台上的 HLS 分片/key/map 和 MP4 Range。
- **尚未部署**：无独立远程仓库创建权限及托管授权，未获得生产 HTTPS 地址。
  本地端口不是手机可长期访问的服务。Windows 关机后可用，仍取决于最终云部署持续运行。
- 免费托管的流量、函数时长、CPU 与服务规则可能限制代理；见[部署说明](deployment.zh-CN.md)。
  不保证长期无限免费；没有开通付费服务。
- 安卓 APK 未生成；已记录共享组件与客户端/服务端提取方案，见[架构文档](private-app-architecture.zh-CN.md)。
